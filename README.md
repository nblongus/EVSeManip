# EVSeManip

**EVSeManip** is an English–Vietnamese benchmark for detecting simulated semantic manipulation in political speech translation.

The benchmark is designed to evaluate whether models can distinguish between faithful translations and translations containing semantic manipulations of different severity levels.

EVSeManip contains three labels:

- **Faithful**
- **Low-severity**
- **High-severity**

The current benchmark consists of **7,599 aligned triplets** derived from **980 U.S. presidential speeches**, resulting in **22,797 labeled instances**.
